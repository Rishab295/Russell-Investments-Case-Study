This repository contains my solution to the **Russell Investments Quantitative Case Study**.

## Projects

### Q1 – Mean Reversion / Statistical Arbitrage

* Identified and constructed a mean-reverting portfolio.
* Performed cointegration and statistical tests.
* Developed and backtested a trading strategy.
* Evaluated performance, risks, and robustness using real market data.

### Q2 – Country Valuation

* Developed a quantitative framework to value countries as economic assets.
* Used real economic and financial data for multiple countries.
* Built a numerical valuation model and compared the results across countries.

## Repository Contents

* **Code** – Python notebooks/scripts used for analysis and modelling
* **Data** – Raw and processed datasets
* **Results** – Charts, tables, and model outputs
* **Report** – Detailed case study analysis and conclusions

## Tools & Technologies

Python • Pandas • NumPy • SciPy • Statsmodels • Matplotlib • Seaborn • Financial/Economic APIs
